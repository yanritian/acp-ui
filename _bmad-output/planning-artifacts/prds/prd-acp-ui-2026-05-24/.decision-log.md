## Decisions

### D001: Product Positioning Correction
- **Date**: 2026-05-24
- **Decision**: Remove Trae本地化, add Codex sandbox, make Hermes pluggable
- **Rationale**: User requirement - Trae not needed, Codex provides second Agent, Hermes should support multiple schedulers (Rust Hermes + Alibaba Coding Plan + future extensions)
- **Impact**: Core architecture change - multi-Agent sandbox with pluggable orchestration

### D002: Three-Layer Sandbox Architecture
- **Date**: 2026-05-24
- **Decision**: Use layered approach (Layer 0/1/2) instead of binary simple/extreme choice
- **Rationale**: Claude Code already has rich features locally; ACP-UI adds remote, multi-platform, GUI dashboard, pet system - incremental enhancement makes sense
- **Impact**: 
  - Layer 0: Core sandbox (Agent process, MCP, remote WebSocket)
  - Layer 1: Enhanced (memory scopes, skills isolation, hooks)
  - Layer 2: Complete (Hermes pet, GUI dashboard, multi-platform cards)

### D003: Platform Priority
- **Date**: 2026-05-24
- **Decision**: Web + Windows-App (Tauri) first, Flutter deferred
- **Rationale**: Flutter has build issues; Web + Tauri cover primary desktop use cases; mobile can follow later
- **Impact**: P0 focus on Vue 3.5 + Tauri 2; Flutter降级为 P1/H5

### D004: Build Fix Priority
- **Date**: 2026-05-24
- **Decision**: Phase 0 = Build修复 before any feature work
- **Rationale**: Previous builds passed but functionality was missing/wrong; need green build as foundation
- **Impact**: Web vue-tsc fix, Tauri/Rust Hermes crates link fix, database types fix

### D005: Target User Scope
- **Date**: 2026-05-24
- **Decision**: 个人开发者自用（非团队协作）
- **Rationale**: User confirmed Q1: A - primary user is solo developer, not team
- **Impact**: Remove team collaboration features; simplify multi-Agent to single-user parallel execution; no RBAC/permissions complexity

### D006: First Usable Version Scope
- **Date**: 2026-05-24
- **Decision**: Phase 1 完成需包含至少一个开发工具适配器
- **Rationale**: User confirmed Q2: C - first usable version should have local + remote + one dev tool adapter (HBuilderX or WeChat DevTools)
- **Impact**: Phase 1 扩展范围，增加适配器集成任务

### D007: Hermes Pet System Priority
- **Date**: 2026-05-24
- **Decision**: Hermes 宠物系统提前到 P1
- **Rationale**: User confirmed Q3: 是 - wants pet system earlier for better UX
- **Impact**: FR-007 从 P2 调整到 P1；Phase 1 增加 Hermes 宠物系统基础功能

### D008: Repositioning - 中国工具链AI编排平台
- **Date**: 2026-05-24
- **Decision**: 重新定位为"中国开发工具链的 AI 编排平台"
- **Rationale**: Party Mode 竞品分析发现国际竞品（MetaGPT/OpenDevin）已做多Agent，国内竞品（通义灵码/Comate）无多Agent；ACP-UI差异化在于中国工具链集成（HBuilderX/微信DevTools）
- **Impact**: 核心差异化从"多Agent"转向"中国工具链 + Docker-like编排 + 智能路由"

### D009: Docker-like Agent 架构
- **Date**: 2026-05-24
- **Decision**: 采用 Docker-like Agent 编排系统（Base/Template/Instance/Team）
- **Rationale**: 用户要求 Claude Code/Codex 作为基底，配置类似 Docker Image/Container 管理；支持 skills/hooks/rules/memory 配置模板化
- **Impact**: 新增 FR-014~016 Agent Registry/Instance/Team 功能需求

### D010: 多维记忆系统
- **Date**: 2026-05-24
- **Decision**: 多层级记录系统：输入层→Agent层→会话层，SQLite + Chroma 混合存储
- **Rationale**: 用户要求监控 Claude Code/Codex 内部流程，记录输入来源（app/robot）、Agent 工具调用和思考过程、会话历史；需要语义检索能力
- **Impact**: 新增 FR-018 多维记忆系统 + FR-019 智能清理

### D011: 智能路由系统
- **Date**: 2026-05-24
- **Decision**: 根据任务特征自动路由到 Claude Code / Codex / Team
- **Rationale**: 用户要求智能决定何时用 Claude Code、何时用 Codex；基于任务类型、输入类型、复杂度、负载自动路由
- **Impact**: 新增 FR-020 智能路由系统

### D012: 自我修复与自进化系统
- **Date**: 2026-05-24
- **Decision**: 新增 SelfHealingProvider/SelfEvolutionProvider/IntelligenceCoordinator 三大 Trait
- **Rationale**: 用户要求 Agent 支持智能、自进化、自我修复；需改造 Hermes Rust 添加主动错误检测、学习机制、智能调度
- **Impact**: 新增 FR-011~013 自我修复/智能调度/自进化功能需求

### D013: 配置同步功能
- **Date**: 2026-05-24
- **Decision**: 支持读取/导入/导出 Claude Code 和 Codex 本地配置
- **Rationale**: 用户要求 ACP-UI 能查看和管理 Claude Code ~/.claude/ 目录的 skills/hooks/rules
- **Impact**: 新增 FR-017 配置同步功能（P2）

### D014: 开源免费策略
- **Date**: 2026-05-24
- **Decision**: 核心代码 Apache 2.0 开源，用户自备 API 密钥
- **Rationale**: 用户要求"免费或开源，功能完整"；对标国际开源产品（Aider/OpenDevin）
- **Impact**: 无订阅费用；阿里 Coding Plan 用户自带密钥或使用官方免费额度

### D015: Phase 优先级调整
- **Date**: 2026-05-24
- **Decision**: Phase 1 合并 Agent 系统 + 记忆系统；Phase 2 增强功能；Phase 3 完整体验 + 开源发布
- **Rationale**: Party Mode 讨论后确定优先级：先打通 Agent Registry + 多维记忆 + 智能路由，再增强 Team 编排和配置同步
- **Impact**: Phase 从 5 阶段调整为 3 阶段，功能更聚焦

## 2026-06-08 Update — Async Controller Repositioning

### D016: 定位从"多 Agent 平台"变为"跨平台异步 AI Agent 控制器"
- **Date**: 2026-06-08
- **Decision**: ACP-UI 核心定位改为"让开发者从'坐在电脑前'变成'随时随地控制'"
- **Rationale**: AI Agent 能力越来越强，但人类不可能 24 小时盯着屏幕；异步是未来
- **Impact**: PRD 1.1/1.2/1.3 全部重写

### D017: 完全开源，5元/月可选便利功能
- **Date**: 2026-06-08
- **Decision**: 先完全开源，社区驱动迭代
- **Rationale**: 开源社区才是最好的增长引擎
- **Impact**: PRD 1.2 差异化更新

### D018: Flutter 从 P1 暂缓升级为 P0
- **Date**: 2026-06-08
- **Decision**: Flutter 移动端完成极简重设计（3 标签：进度/审批/指令）
- **Rationale**: 异步控制需要移动端才能完整体验
- **Impact**: PRD 3.3 多端架构更新，FR-009 新增

### D019: 驾驭而非替代
- **Date**: 2026-06-08
- **Decision**: ACP-UI 不做专业 Agent，而是驾驭 Claude Code/Codex/Cursor 等已有 Agent
- **Rationale**: 每个专业 Agent 都是独立的强工具，ACP-UI 的价值在于编排
- **Impact**: FR-001 重写，移除 Docker-like Agent 编排的过度设计

### D020: 移除 HBuilderX/微信 DevTools 作为核心差异化
- **Date**: 2026-06-08
- **Decision**: 中国工具链不再作为核心差异化
- **Rationale**: 定位转变后，多平台 Bot（飞书/Telegram/Discord）更重要
- **Impact**: PRD 1.2 差异化表更新

### D021: Phase 9 架构改造完成
- **Date**: 2026-06-08
- **Decision**: 8 个新模块全部完成，+5,517 行新增代码
- **Rationale**: 异步控制器架构需要这些核心模块
