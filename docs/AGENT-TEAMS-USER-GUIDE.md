## 概述

Agent Teams Platform 是一个多Agent协作可视化平台，提供：

- **实时进度监控**：查看Agent思考过程、工具调用、输出结果
- **类人宠物系统**：与Agent互动，提升快乐度和亲密度
- **协作网络可视化**：流程图、时间线、看板三种视图
- **三端同步**：Web + auri桌面端 + Flutter移动端数据同步

## 快速开始

### 启动应用

```bash
# Web端
npm run dev

# Tauri桌面端
npm run tauri dev

# Flutter移动端
cd acp_ui_flutter && flutter run
```

### 访问Agent Teams

1. 启动应用后，打开侧边栏导航
2. 点击 **🚀 Agent Teams** 按钮
3. 进入Agent Teams Platform主页

## Agent宠物系统

### 宠物状态

每个Agent都有对应的宠物形象，显示：

| 属性 | 说明 |
|------|------|
| **表情** | 😐平静 / 😊开心 / 😴疲惫 / 🤔困惑 / 🎉兴奋 |
| **等级** | Lv.1 新手 → Lv.5 大师 |
| **状态** | 💭思考 / ⚡执行 / 😴空闲 / 💤等待 |

### 互动操作

点击宠物卡片的互动按钮：

| 按钮 | 效果 |
|------|------|
| 👋 **抚摸** | +5 快乐度 |
| 👉 **戳一下** | -2 快乐度 |
| 🍖 **喂食** | +10 快乐度 +5 亲密度 |
| 🎾 **玩耍** | +15 快乐度 +10 亲密度 |

### 成长系统

```
等级晋升路径：
┌─────────────────────────────────────────┐
│ Lv.1 新手 → Lv.2 学徒 → Lv.3 熟练       │
│      ↓                                   │
│ Lv.4 专家 → Lv.5 大师                   │
└─────────────────────────────────────────┘

经验获取：
- 完成任务：+10 EXP
- 快速执行（<30s）：额外 +10 EXP
- 连续成功：解锁成就奖励
```

### 成就解锁

| 成就名称 | 条件 |
|----------|------|
| 🏆 初出茅庐 | 完成第一个任务 |
| 📈 小有成就 | 完成10个任务 |
| ⭐ 经验丰富 | 完成50个任务 |
| 🎖️ 大师级 | 完成100个任务 |
| ✨ 完美执行 | 连续10个任务成功 |
| ⚡ 闪电执行 | 平均执行时间 <30秒 |
| 🧠 深度思考 | 思考时间 >5分钟 |

## 协作网络可视化

### 三种视图模式

#### 1. 🕸️ 网络流程图

显示Agent之间的任务流转关系：

```
┌──────────┐    任务分配    ┌──────────┐
│ Planner  │ ────────────→ │ Architect │
│  📋      │               │  🏗️      │
│ 负载:33% │               │ 负载:50%  │
└──────────┘               └──────────┘
      │                          │
      │ 设计方案                  │ 测试方案
      ↓                          ↓
┌──────────┐               ┌──────────┐
│ TDD Guide│               │ Security │
│  🧪      │               │  🔒      │
│ 负载:33% │               │ 负载:50%  │
└──────────┘               └──────────┘
```

**节点信息**：
- Agent类型图标
- 当前负载百分比
- 能力标签
- 状态指示（⚡活跃 / 💤空闲）

**边信息**：
- 任务流向
- 状态：Flowing / Pending / Completed
- 耗时

#### 2. ⏱️ 时间线视图

按时间顺序展示任务执行：

```
时间轴
─────────────────────────────────────────────→
     │         │         │         │

     │         │         │         │
   19:48     19:49     19:50     19:51
     
里程碑：
├── 🎯 任务启动
├── 📐 设计完成
├── 🧪 测试通过
├── ✅ 任务完成
```

#### 3. 📋 看板视图

按状态分组管理任务：

```
┌────────────┐  ┌────────────┐  ┌────────────┐
│   待处理   │  │   进行中   │  │   已完成   │
├────────────┤  ├────────────┤  ├────────────┤
│ □ 架构设计 │  │ ▶ 代码审查 │  │ ✓ 需求分析 │
│ □ 安全审计 │  │ ▶ 单元测试 │  │ ✓ 规划完成 │
│ □ 性能优化 │  │            │  │ ✓ 文档更新 │
└────────────┘  └────────────┘  └────────────┘
```

**拖拽功能**：
- 拖动任务卡片切换状态

```
┌─────────────┐     WebSocket      ┌─────────────┐

└─────────────┘                    └─────────────┘
       ↑                                  │
       │                                  │
       │         ┌─────────────┐          │
       │         │ Tauri桌面端 │ ←────────┤
       │         │  本地应用   │          │
       │         └─────────────┘          │
       │                                  │
       │         ┌─────────────┐          │
       └─────────│ Flutter移动 │ ←────────┤
                 │  手机App    │          │
                 └─────────────┘          │
```

### 同步内容

| 数据类型 | 同频频率 |
|----------|----------|
| Agent状态 | 实时 |
| 任务进度 | 实时 |
| 宠物互动 | 实时 |
| 协作事件 | 实时 |
| 统计数据 | 2秒间隔 |

### 状态指示

- 🟢 **已连接**：三端同步正常
- 🟡 **待连接**：部分端未连接
- 🔴 **断开**：同步服务断开

## 常见问题

### Q1: Agent宠物表情为什么不变化？

**A**: 宠物表情根据Agent当前状态自动变化：
- 执行任务时显示 🤔 思考
- 任务成功时显示 😊 开心
- 空闲等待时显示 😴 疲惫
- 互动后根据效果变化

### Q2: 如何提高宠物等级？

**A**: 通过以下方式获取经验值：
1. 完成更多任务（每个任务 +10 EXP）
2. 快速执行任务（<30秒额外 +10 EXP）
3. 保持连续成功（解锁成就奖励）
4. 定期互动（提升亲密度）

### Q3: 协作网络图如何操作？

**A**: 
- **拖拽节点**：调整Agent位置
- **点击节点**：查看Agent详情
- **点击边**：查看任务流转信息
- **缩放**：鼠标滚轮或控件按钮
- **全屏**：点击全屏按钮

### Q4: 三端同步断开怎么办？

**A**: 
1. 检查Gateway服务是否启动
2. 认WebSocket连接配置正确
3. 刷新页面重新连接
4. 查看控制台错误日志

### Q5: 语言切换后部分文字仍显示英文？

**A**: 
- 技术术语如"Agent"、"WebSocket"等保留英文是行业标准
- 如需完全翻译，可在设置中调整翻译偏好
