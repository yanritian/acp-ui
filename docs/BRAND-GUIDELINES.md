## 标志使用

### 主标志

**使用规范**:
- ✅ 保持原始比例
- ✅ 使用官方颜色
- ✅ 留出足够的空白区域
- ✅ 在深色背景上使用浅色版本

**避免**:
- ❌ 拉伸或压缩
- ❌ 更改颜色
- ❌ 添加效果（阴影、渐变等）
- ❌ 旋转变形
- ❌ 在复杂背景上使用

### 标志尺寸

**最小尺寸**:
- 数字媒体: 32px 高度
- 印刷媒体: 10mm 高度

**空白区域**:
- 标志周围至少留出标志高度 25% 的空白

### 标志变体

1. **全彩标志**: 主要使用
2. **单色标志**: 黑白印刷
3. **反白标志**: 深色背景
4. **图标标志**: 小尺寸应用

## 颜色规范

### 主色调

```css
/* 主色 - 科技蓝 */
--primary-color: #3B82F6;
--primary-dark: #2563EB;
--primary-light: #60A5FA;

/* 辅助色 - 成功绿 */
--success-color: #10B981;
--success-dark: #059669;
--success-light: #34D399;

/* 警告色 - 橙黄 */
--warning-color: #F59E0B;
--warning-dark: #D97706;
--warning-light: #FBBF24;

/* 错误色 - 红色 */
--error-color: #EF4444;
--error-dark: #DC2626;
--error-light: #F87171;
```

### 中性色

```css
/* 文字色 */
--text-primary: #111827;
--text-secondary: #6B7280;
--text-tertiary: #9CA3AF;

/* 背景色 */
--bg-primary: #FFFFFF;
--bg-secondary: #F9FAFB;
--bg-tertiary: #F3F4F6;

/* 边框色 */
--border-primary: #E5E7EB;
--border-secondary: #D1D5DB;
```

### 颜色使用原则

1. **主色**: 用于主要按钮、链接、重点元素
2. **辅助色**: 用于成功状态、正面反馈
3. **警告色**: 用于警告信息、注意事项
4. **错误色**: 用于错误状态、危险操作
5. **中性色**: 用于文本、背景、边框

## 语言风格

### 语调

- **专业**: 技术准确、用词严谨
- **友好**: 平易近人、易于理解
- **积极**: 正面、鼓励、建设性
- **简洁**: 直接、清晰、不冗长

### 写作原则

1. **使用主动语态**
   - ✅ "点击按钮保存文件"
   - ❌ "文件可以通过点击按钮被保存"

2. **避免行话**
   - ✅ "使用这个工具可以..."
   - ❌ "利用该实用程序能够..."

3. **提供上下文**
   - ✅ "为了提高性能，我们优化了..."
   - ❌ "我们优化了代码"

4. **使用一致术语**
   - 统一使用 "操作员" 而不是混用 "代理"、"机器人"
