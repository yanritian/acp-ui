## 格式说明

### 版本号规则

遵循语义化版本规范 (Semantic Versioning):

- **MAJOR**: 不兼容的 API 变更
- **MINOR**: 向下兼容的功能新增
- **PATCH**: 向下兼容的问题修正

### 变更类型

- **Added**: 新功能
- **Changed**: 现有功能的变更
- **Deprecated**: 即将废弃的功能
- **Removed**: 已移除的功能
- **Fixed**: 问题修复
- **Security**: 安全修复

### 日期格式

使用 ISO 8601 格式: YYYY-MM-DD

5. **保持格式一致**
