## 参与方式

### 1. 使用项目

最简单的参与方式就是使用项目：

```bash
# 克隆仓库
git clone https://github.com/yanritian/acp-ui.git
cd acp-ui

# 安装依赖
npm install

# 启动应用
npm run dev
```

### 2. 报告问题

发现问题时，请：

1. 检查是否已有相同 Issue
2. 创建新的 Issue
3. 提供详细信息
4. 附上截图或日志

### 3. 提出建议

有好想法时，请：

1. 在 Discussions 中发起讨论
2. 描述你的想法
3. 解释为什么这很重要
4. 听取社区反馈

### 4. 贡献代码

贡献代码时，请：

1. 阅读 [CONTRIBUTING.md](../CONTRIBUTING.md)
2. Fork 仓库
3. 创建功能分支
4. 提交 Pull Request

### 5. 改进文档

改进文档时，请：

1. 发现文档问题
2. 提交修复 PR
3. 或创建 Issue

### 6. 帮助他人

帮助他人时，请：

1. 回答 Discussions 中的问题
2. 帮助审查 Pull Request
3. 分享使用经验
4. 创建教程和示例

## 行为准则

我们遵循 [Contributor Covenant](https://www.contributor-covenant.org/) 行为准则。

### 我们的承诺

为了营造一个开放和友好的环境，我们承诺：

- 使用友好和包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事情

### 不可接受的行为

包括但不限于：

- 使用性化的语言或图像
- 人身攻击或侮辱性评论
- 公开或私下骚扰
- 未经许可发布他人信息
- 其他不道德或不专业的行为

### 执行

如发现不可接受的行为，请：

1. 联系项目负责人
2. 提供详细信息
3. 等待调查和处理

## 社区活动

### 1. 定期会议

- **频率**: 每月一次
- **形式**: 线上会议
- **内容**: 项目进展、问题讨论、规划未来

### 2. 黑客松

- **频率**: 每季度一次
- **形式**: 线上/线下

### 3. 工作坊

- **频率**: 不定期
- **形式**: 线上
- **内容**: 教学和指导

### 4. 社交活动

- **频率**: 不定期
- **形式**: 线上/线下
- **内容**: 社区聚会和交流

## 常见问题

### Q: 如何开始贡献？

**A**: 阅读 [CONTRIBUTING.md](../CONTRIBUTING.md)，从小任务开始。

### Q: 需要多长时间才能成为核心成员？

**A**: 取决于贡献质量和频率，通常需要 3-6 个月。

### Q: 可以获得报酬吗？

**A**: 这是开源项目，目前没有报酬，但有其他形式的认可。

### Q: 如何组织本地聚会？

**A**: 联系项目负责人，我们可以提供支持和资源。
