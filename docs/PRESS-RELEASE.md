## 🎯 核心亮点

### 五大客户端平台

ACP-UI 支持五个主要平台，为开发者提供无缝体验：

- **Desktop** - Windows, macOS, Linux 桌面应用
- **VSCode Extension** - Visual Studio Code 集成
- **IntelliJ IDEA Plugin** - JetBrains IDE 集成
- **Web** - 基于 Vue 3 的网页应用
- **Mobile** - Flutter 移动应用

### 13种语言支持

完整的国际化支持，覆盖全球开发者：

简体中文、繁体中文、英语、葡萄牙语（巴西）、德语、西班牙语、俄语、日语、韩语、越南语、泰语、马来语、法语

### 1,278个测试

严格的质量保证，100%测试通过率，85%+代码覆盖率

### 完整文档体系

39个主要文档，覆盖开发、运维、管理、社区所有方面

## 💡 主要特性

### 智能审批系统

4级审批机制（silent、notify、approve、forbidden），确保操作安全可靠

### 安全守卫

PathGuard 和 CommandGuard 双重保护，防止未授权操作

### 状态机管理

完整的任务生命周期管理（Idle → Planning → Running → Completed）

### 文件工具

完整的文件操作工具集（read、write、patch、patch_preview、list）

## 🏢 关于 ACP-UI

ACP-UI 是一个开源的多平台 Agent 系统，专注于游戏开发。通过统一的界面和智能化的 Agent 管理，帮助开发者更高效地创建游戏。

### 核心技术

- **前端**: Vue 3 + TypeScript
- **后端**: Tauri (Rust)
- **移动端**: Flutter
- **测试**: Vitest (1,278个测试)
