# 项目宣传海报设计指南

> 版本: 1.0
> 日期: 2026-07-12
> 用途: 项目宣传、会议展示、社交媒体

---

## 🎨 海报规格

### 标准尺寸

**A3 海报** (297 x 420 mm)
- 分辨率: 300 DPI
- 用途: 会议展示、打印

**A4 海报** (210 x 297 mm)
- 分辨率: 300 DPI
- 用途: 小型展示、分发

**数字海报** (1920 x 1080 px)
- 分辨率: 72 DPI
- 用途: 社交媒体、网站

## 🎨 视觉设计

### 配色方案

```css
/* 主色调 */
--primary: #3B82F6;        /* 科技蓝 */
--primary-dark: #2563EB;
--primary-light: #60A5FA;

/* 辅助色 */
--success: #10B981;        /* 成功绿 */
--warning: #F59E0B;        /* 警告橙 */
--error: #EF4444;          /* 错误红 */

/* 中性色 */
--text-dark: #111827;
--text-light: #6B7280;
--bg-white: #FFFFFF;
--bg-gray: #F9FAFB;
```

### 字体选择

**英文**:
- 标题: Inter Bold, 48-72px
- 副标题: Inter SemiBold, 32-48px
- 正文: Inter Regular, 18-24px

**中文**:
- 标题: 思源黑体 Bold, 48-72px
- 副标题: 思源黑体 Medium, 32-48px
- 正文: 思源黑体 Regular, 18-24px

### 图标风格

- 线性图标
- 2px 描边
- 圆角设计
- 使用品牌色

## 📝 内容要素

### 必要元素

1. **项目 Logo** (顶部居中)
2. **项目名称** (大标题)
3. **项目口号** (副标题)
4. **核心数据** (3个关键指标)
5. **核心特性** (5-7个要点)
6. **技术栈** (简要说明)
7. **GitHub 链接** (二维码或文字)
8. **版本号** (v0.1.0-alpha)

### 可选元素

- 项目截图
- 架构图
- 使用案例
- 社交媒体账号
- 赞助商 Logo

## 📱 不同平台版本

### 印刷版本 (A3/A4)

- 分辨率: 300 DPI
- 色彩模式: CMYK
- 出血: 3mm
- 格式: PDF

### 数字版本 (Web)

- 分辨率: 72 DPI
- 色彩模式: RGB
- 格式: PNG/JPG
- 尺寸: 1920x1080px

### 社交媒体版本

**Twitter/Facebook**:
- 尺寸: 1200x630px
- 格式: JPG/PNG
- 大小: < 5MB

**Instagram**:
- 尺寸: 1080x1080px
- 格式: JPG/PNG
- 大小: < 5MB

**LinkedIn**:
- 尺寸: 1200x627px
- 格式: JPG/PNG
- 大小: < 5MB
