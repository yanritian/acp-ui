## 🚀 常用命令

### 开发命令

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 启动Web开发服务器
npm run dev:web

# 运行测试
npm test

# 运行测试（监听模式）
npm run test:watch

# 运行E2E测试
npm run test:e2e

# 类型检查
npm run typecheck

# 构建生产版本
npm run build

# 仅构建前端
npm run build:only

# 构建Web版本
npm run build:web

# 预览生产版本
npm run preview

# 预览Web版本
npm run preview:web
```

### Tauri 命令

```bash
# 进入Tauri目录
cd src-tauri

# 检查代码
cargo check

# 构建调试版本
cargo build

# 构建发布版本
cargo build --release

# 运行测试
cargo test

# 启动Tauri应用
cargo tauri dev

# 构建桌面应用
cargo tauri build
```

### Git 命令

```bash
# 查看状态
git status

# 添加文件
git add .

# 提交更改
git commit -m "message"

# 推送到远程
git push origin main

# 创建标签
git tag v0.1.0

# 推送标签
git push origin v0.1.0

# 查看日志
git log --oneline

# 查看分支
git branch -a
```

## 🎯 快速任务

### 创建新操作员

1. 点击"新建操作员"
2. 选择项目路径
3. 配置参数
4. 点击"创建"

### 启动任务

1. 选中操作员
2. 点击"启动"或按 `Ctrl+Enter`
3. 观察进度

### 处理审批

1. 查看审批队列
2. 点击审批项
3. 查看详情
4. 批准或拒绝

### 切换语言

1. 点击设置图标
2. 选择"语言"
3. 选择语言
4. 自动切换
