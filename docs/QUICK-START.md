# Hermes Game Operator 快速开始

> 5 分钟快速上手指南

---

## 1. 前置条件检查

```bash
# 检查 Node.js
node --version  # 需要 >= 18.x

# 检查 Rust
rustc --version  # 需要 >= 1.70

# 检查 Hermes CLI (可选)
hermes --version
```

---

## 2. 安装依赖

```bash
# 克隆项目
git clone https://github.com/your-org/acp-ui.git
cd acp-ui

# 安装前端依赖
npm install
```

---

## 3. 启动开发服务器

```bash
npm run tauri dev
```

---

## 4. 使用流程

1. 选择 Godot 项目目录
2. 输入任务目标
3. 点击 Start Task
4. 审批文件修改
5. 查看结果
