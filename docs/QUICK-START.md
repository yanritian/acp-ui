# Agent Teams Platform 快速入门

## 5分钟上手指南

### 第一步：启动应用

```bash
npm run dev
# 访问 http://localhost:1420
```

### 第二步：导航到Agent Teams

点击侧边栏 **🚀 Agent Teams** 按钮

### 第三步：探索功能

```
┌──────────────────────────────────────────────┐
│  🤖 4个Agent已就绪                            │
│  - Planner (规划师)                           │
│  - Architect (架构师)                         │
│  - TDD Guide (测试专家)                       │
│  - Code Reviewer (代码审查员)                 │
├──────────────────────────────────────────────┤
│  切换视图：                                   │
│  [📊全部] [⚡进度] [🕸️协作] [🐱宠物]           │
├──────────────────────────────────────────────┤
│  三端同步：🟢 已连接                          │
└──────────────────────────────────────────────┘
```

## 核心操作速查

### 🐱 与宠物互动

| 按钮 | 效果 | 用途 |
|------|------|------|
| 👋 | +5快乐 | 提升心情 |
| 🍖 | +10快乐+5亲密 | 增进关系 |
| 🎾 | +15快乐+10亲密 | 最佳互动 |

### 🕸️ 协作网络操作

| 操作 | 方法 |
|------|------|
| 拖动节点 | 鼠标拖拽 |
| 查看详情 | 点击节点 |
| 切换视图 | 点击底部按钮 |
| 缩放 | 滚轮/控件 |

### ⏱️ 时间线解读

```
🎯 开始 → 📐 设计 → 🧪 测试 → ✅ 完成
  0s      30s       60s       90s
```

## 常用快捷键

```
Ctrl + 1  → 全部视图
Ctrl + 2  → 进度视图  
Ctrl + 3  → 协作视图
Ctrl + 4  → 宠物视图
Ctrl + L  → 切换语言
?         → 显示帮助
```

---

## 状态图标含义

| 图标 | 含义 |
|------|------|
| 💭 | 正在思考 |
| ⚡ | 正在执行 |
| 😴 | 空闲等待 |
| ✅ | 任务完成 |
| ❌ | 任务失败 |
| 🟢 | 同步正常 |
| 🟡 | 部分连接 |
| 🔴 | 断开连接 |
