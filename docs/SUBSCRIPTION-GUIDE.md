## 📋 订阅方式

### 1. GitHub 通知

**最简单的方式**

1. 访问 https://github.com/yanritian/acp-ui
2. 点击 "Watch" 按钮
3. 选择通知级别：
   - **Watching**: 所有活动
   - **Releases only**: 仅版本发布
   - **Custom**: 自定义通知
   - **Ignoring**: 不接收通知

**推荐**: 选择 "Releases only"

### 2. RSS 订阅

**使用 RSS 阅读器**

```
 releases: https://github.com/yanritian/acp-ui/releases.atom
 commits:  https://github.com/yanritian/acp-ui/commits/main.atom
 issues:   https://github.com/yanritian/acp-ui/issues.atom
```

### 3. 邮件订阅

**通过 GitHub**

1. 在仓库页面点击 "Watch"
2. 确保邮箱通知已启用
3. 选择要接收的通知类型

### 4. 社交媒体

**关注官方账号**

- **Twitter/X**: @acp_ui (即将推出)
- **LinkedIn**: ACP-UI (即将推出)
- **Reddit**: r/acp_ui (即将推出)

### 5. 新闻通讯

**定期邮件更新**

即将推出月度新闻通讯，包括：
- 版本发布
- 新功能介绍
- 社区活动
- 教程和指南

## 📊 通知管理

### 减少噪音

**GitHub 设置**:

1. 访问 https://github.com/settings/notifications
2. 调整通知偏好：
   - Automatically watch repositories: 关闭
   - Participating: 开启
   - Watching: 开启
   - Ignored: 关闭

### 批量处理

**使用 GitHub 通知面板**:

1. 访问 https://github.com/notifications
2. 批量标记已读
3. 批量订阅/取消订阅
4. 使用过滤器

## ❓ 常见问题

### Q: 如何取消订阅？

**A**: 
1. 访问仓库页面
2. 点击 "Watched" 按钮
3. 选择 "Unwatch"

### Q: 收不到通知怎么办？

**A**: 
1. 检查 GitHub 通知设置
2. 检查邮箱垃圾邮件
3. 确保邮箱已验证
4. 联系支持

### Q: 可以只接收特定类型的通知吗？

**A**: 
可以，使用 "Custom" 选项选择特定类型。

### Q: 有中文通知吗？

**A**: 
目前主要是英文，计划添加中文支持。
