## 🚀 快速开始

### 安装

1. **下载**
   - 访问 [GitHub Releases](https://github.com/yanritian/acp-ui/releases)
   - 选择适合您操作系统的版本
   - 下载安装包

2. **安装**
   - **Windows**: 双击 MSI 或 EXE 文件
   - **macOS**: 打开 DMG 文件，拖入 Applications
   - **Linux**: 使用包管理器安装 DEB/RPM 或运行 AppImage

3. **启动**
   - 双击桌面图标或从应用菜单启动

### 首次使用

1. **创建操作员**
   - 点击"新建操作员"
   - 选择 Godot 项目路径
   - 配置 Agent 参数
   - 点击"创建"

2. **启动任务**
   - 选中操作员
   - 点击"启动"按钮
   - 观察进度和事件

3. **处理审批**
   - 查看审批队列
   - 审查操作详情
   - 批准或拒绝

4. **查看结果**
   - 查看任务摘要
   - 浏览事件流
   - 导出结果

## 📚 详细指南

### 主界面

#### 导航栏（左侧）

- **操作员列表**: 显示所有操作员
- **设置**: 应用设置
- **帮助**: 获取帮助

#### 主工作区（中间）

- **操作员状态**: 当前状态和进度
- **任务信息**: 任务详情
- **事件流**: 实时事件

#### 审批队列（右侧）

- **待审批项**: 需要审批的操作
- **已审批项**: 历史审批记录

#### 工具栏（顶部）

- **新建**: 创建新操作员
- **启动**: 启动选中操作员
- **停止**: 停止选中操作员
- **设置**: 打开设置

### 操作员管理

#### 创建操作员

1. 点击"新建操作员"
2. 填写项目路径
3. 配置 Agent 参数：
   - **模型**: 选择 AI 模型
   - **温度**: 控制创造性（0-2）
   - **最大令牌**: 限制输出长度
4. 点击"创建"

#### 编辑操作员

1. 右键点击操作员
2. 选择"编辑"
3. 修改参数
4. 点击"保存"

#### 删除操作员

1. 右键点击操作员
2. 选择"删除"
3. 确认删除

### 任务管理

#### 启动任务

1. 选中操作员
2. 点击"启动"或按 `Ctrl+Enter`
3. 观察状态变化

#### 暂停任务

1. 选中正在运行的操作员
2. 点击"暂停"
3. 任务暂停

#### 恢复任务

1. 选中暂停的操作员
2. 点击"恢复"
3. 任务继续

#### 停止任务

1. 选中正在运行的操作员
2. 点击"停止"
3. 确认停止

### 审批系统

#### 查看审批队列

1. 点击右侧"审批队列"面板
2. 查看待审批项列表
3. 点击项目查看详情

#### 审批操作

**批准**:
1. 查看操作详情
2. 点击"批准"按钮
3. 可选：添加批准原因

**拒绝**:
1. 查看操作详情
2. 点击"拒绝"按钮
3. 填写拒绝原因（必填）

#### 批量审批

1. 选中多个审批项
2. 点击"批量批准"或"批量拒绝"
3. 确认操作

### 文件工具

#### 读取文件

1. 在任务中选择"读取文件"
2. 输入文件路径
3. 查看文件内容

#### 写入文件

1. 在任务中选择"写入文件"
2. 输入文件路径
3. 输入文件内容
4. 确认写入

#### 应用补丁

1. 在任务中选择"应用补丁"
2. 输入文件路径
3. 输入补丁内容
4. 预览更改
5. 确认应用

#### 列出目录

1. 在任务中选择"列出目录"
2. 输入目录路径
3. 查看目录内容

### 设置

#### 通用设置

- **语言**: 选择界面语言（13种）
- **主题**: 选择界面主题
- **自动更新**: 启用自动更新

#### 安全设置

- **PathGuard**: 启用路径访问控制
- **CommandGuard**: 启用命令执行控制
- **允许路径**: 配置允许访问的路径
- **阻止路径**: 配置阻止访问的路径

#### 通知设置

- **桌面通知**: 启用桌面通知
- **声音提醒**: 启用声音提醒
- **邮件通知**: 启用邮件通知

## 🎯 高级功能

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建操作员 |
| `Ctrl+Enter` | 启动操作员 |
| `Ctrl+Shift+A` | 打开审批队列 |
| `Ctrl+Shift+S` | 保存设置 |
| `Ctrl+Q` | 退出应用 |
| `F1` | 打开帮助 |
| `F5` | 刷新 |

### 多语言支持

1. 点击设置图标
2. 选择"语言"
3. 从下拉列表选择语言
4. 界面自动切换

支持的语言：
- 简体中文 (zh-CN)
- 繁体中文 (zh-TW)
- 英语 (en-US)
- 葡萄牙语-巴西 (pt-BR)
- 德语 (de-DE)
- 西班牙语 (es-ES)
- 俄语 (ru-RU)
- 日语 (ja-JP)
- 韩语 (ko-KR)
- 越南语 (vi-VN)
- 泰语 (th-TH)
- 马来语 (ms-MY)
- 法语 (fr-FR)

### 数据导出

#### 导出任务结果

1. 完成的任务
2. 点击"导出"
3. 选择格式（JSON, CSV, YAML）
4. 选择保存位置
5. 点击"保存"

#### 导出事件流

1. 打开事件流面板
2. 点击"导出事件"
3. 选择时间范围
4. 选择格式
5. 保存文件

## 🔧 故障排除

### 常见问题

#### 应用无法启动

**解决方案**:
1. 检查系统要求
2. 重新安装应用
3. 查看日志文件
4. 联系支持

#### 操作员创建失败

**解决方案**:
1. 检查项目路径是否正确
2. 检查权限
3. 查看错误信息
4. 重试创建

#### 审批队列不显示

**解决方案**:
1. 刷新页面
2. 检查网络连接
3. 查看日志
4. 重启应用

#### 性能问题

**解决方案**:
1. 关闭不必要的应用
2. 增加内存
3. 清理缓存
4. 重启应用

### 日志查看

**日志位置**:
- **Windows**: `%APPDATA%\acp-ui\logs\`
- **macOS**: `~/Library/Application Support/acp-ui/logs/`
- **Linux**: `~/.config/acp-ui/logs/`
