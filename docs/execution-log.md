## 七、恢复指南

### 如果 Claude Code 会话中断

1. **查看本文件**: `docs/execution-log.md`
2. **检查最后状态**: 查看"执行状态总览"表格
3. **检查 Phase 日志**: 找到当前 Phase 的最后一个已完成任务
4. **继续执行**: 从下一个任务开始

### 恢复步骤

```bash
# 1. 检查分支状态
git branch
git status

# 2. 检查构建状态
npm run build
cargo check --manifest-path src-tauri/Cargo.toml

# 3. 查看进度文件
cat docs/implementation-progress.md
cat docs/execution-log.md

# 4. 继续执行
# 从最后一个已完成任务 + 1 开始
```
