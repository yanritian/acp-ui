# ACP UI 修复计划 - 2026-05-31

## 目标
让 ACP UI 成为真正可用的远程 Agent 控制平台，支持飞书 Bot 远程控制。

## 问题分析

### 已完成
1. ✅ 简化导航：24 → 5 个按钮
2. ✅ 欢迎屏幕：快速开始指南 + 核心功能展示
3. ✅ 国际化：中英文支持

### 核心问题
1. **Agent 连接** - 所有 Agent 显示"未连接"，用户无法实际使用
2. **Bot 配置** - 只保存到 localStorage，没有真正的后端服务
3. **Mock 数据** - 协作网络显示假数据，误导用户
4. **空白聊天** - 选择 Agent 后没有引导消息

## 技术细节

### Agent 配置数据结构
```typescript
interface AgentConfig {
  id: string;
  name: string;
  url: string;      // ws:// or wss://
  token?: string;   // Bearer token
  enabled: boolean;
}
```

### Bot 服务架构
```
飞书用户 → 飞书平台 → Webhook → Rust Bot Service
                                      ↓
                              WebSocket Client
                                      ↓
                              Agent (ACP Server)
                                      ↓
                              执行任务 → 返回结果
                                      ↓
                              飞书平台 → 飞书用户
```

### 存储方案
- Agent 配置: `~/.acp-ui/agents.json`
- Bot 配置: `~/.acp-ui/bot-config.json`
- 会话历史: `~/.acp-ui/sessions/`
