## ✅ Phase 5: 运行修复 (已完成 - 2026-06-05)

**目标**: 修复 Web/Tauri 运行时的初始化问题

| 任务 | 状态 | 修复内容 |
|------|------|---------|
| P5.1 Session Store初始化 | ✅ | 移除 setup 内的 storeToRefs，改用 computed 包装 |
| P5.2 Tauri API平台检测 | ✅ | useBotCommand.ts 添加 isDesktop 检测 |

**问题原因分析**:
1. `storeToRefs(otherStore)` 在 setup store 的 setup 函数内部调用时，子 store 可能还未完全绑定到 Pinia 实例
2. `@tauri-apps/api/event` 的 `listen` 函数在 Web 浏览器中不可用，需要平台检测

#### P0.1 数据持久化验证与修复

**修复内容**:
1. `src/stores/session.ts`:
   - 添加 `saveMessages()` / `loadMessages()` / `deleteMessages()` 函数
   - 添加 `beforeunload` 紧急保存（localStorage同步写入）
   - 添加 debounced 自动保存（500ms延迟）
   - 添加 messageWatchStop 管理消息监听
   - 添加会话探活机制（session not found时自动删除过期会话）

2. 消息存储格式：`messages.json` 中的 `{sessionId: ChatMessage[]}`

#### P0.2 Agent 连接稳定性

**修复内容**:
1. `src/stores/session.ts`:
   - 实现指数退避自动重连（配置：maxRetries=5, baseDelay=1s, maxDelay=30s）
   - 扩展重连触发场景：online事件、focus事件、WebSocket意外关闭
   - 重连成功后重置计数器
   - 添加 `cancelAutoReconnect()` 在disconnect时停止重连

#### P0.3 模拟功能处理

**修复内容**:
1. `src/components/TaskGraphView.vue`:
   - 添加 `isDemo` prop标识演示数据
   - 添加黄色警告横幅显示演示说明
   - 添加中英文翻译键 `taskGraph.demoWarning`

2. `src/router.ts`:
   - 更新task-graph路由props添加 `isDemo: true`

## Phase 1: 稳定基础 (预计 5-7 天)

**目标**: 修复所有 P0 阻塞性问题，确保核心功能可用

### 任务清单

#### 1.1 数据持久化验证与修复 (P0.1) [优先级: 最高]

**步骤**:
1. 编写持久化测试脚本
2. 修复 `session.ts` 中 `watch` 保存时机
3. 会话列表探活机制

**风险**: 修改持久化逻辑可能引入数据丢失
**回退策略**: 保留原有 KVStore 逻辑，新增同步保存仅作为 fallback

#### 1.2 Agent 连接稳定性 (P0.2) [优先级: 最高]

**步骤**:
1. 实现指数退避自动重连
2. 扩展重连触发场景
3. stdio agent 启动超时提示

**风险**: 自动重连可能导致资源泄漏
**回退策略**: 提供配置开关 `autoReconnect: false`

#### 1.3 模拟功能处理 (P0.3) [优先级: 高]

**步骤**:
1. Hermes Dashboard 真实数据接入或标注"(演示)"
2. TaskGraphView 添加说明或移除
3. StatusView/MonitorView 补数据源

#### 1.4 平台差异友好提示 (P0.4) [优先级: 中]

**步骤**:
1. Web 版 stdio agent 提示
2. 文件系统错误提示改进

#### 1.5 国际化补齐 (P0.5) [优先级: 中]

**步骤**:
1. 翻译键一致性检查
2. 硬编码文本修复

#### 1.6 构建问题 (P0.6) [优先级: 低]

**步骤**:
1. TypeScript 严格模式清理
2. 构建耗时优化
