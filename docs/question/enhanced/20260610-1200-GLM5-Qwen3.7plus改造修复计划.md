#### 0.1 修复 InstantWrapper 时间语义错误

**文件**: `src-tauri/src/queen_lease.rs` 第 82-92 行、`src-tauri/src/swarm_adapters/mod.rs` 第 163-175 行

**问题**: `InstantWrapper` 存储 `instant.elapsed()` 而非绝对时间戳，导致 `check_validity()` 永远返回 `true`，租约永远不过期。

**修复方案**:
```rust
// 删除 InstantWrapper，直接使用 SystemTime + UNIX 时间戳
pub struct QueenLease {
    pub granted_at: u64,      // UNIX 毫秒时间戳
    pub expires_at: u64,      // UNIX 毫秒时间戳
    pub ttl_seconds: u64,
    // ...
}

impl QueenLease {
    pub fn check_validity(&self) -> bool {
        let now_ms = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .map(|d| d.as_millis() as u64)
            .unwrap_or(0);
        now_ms < self.expires_at
    }

    pub fn remaining_time(&self) -> u64 {
        let now_ms = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .map(|d| d.as_millis() as u64)
            .unwrap_or(0);
        self.expires_at.saturating_sub(now_ms) / 1000
    }
}
```

**验证**: `check_validity()` 在 TTL 过期后返回 `false`；`remaining_time()` 随时间递减。

pub struct Goal {
    pub id: String,
    pub description: String,
    pub completion_condition: CompletionCondition,
    pub evaluator: Evaluator,
    pub assigned_worker: Option<WorkerId>,
    pub status: GoalStatus,
    pub iterations: Vec<IterationRecord>,
    pub max_iterations: u32,
    pub token_budget: Option<u64>,
    pub token_used: u64,
    pub created_at: u64,
    pub started_at: Option<u64>,

}

pub enum CompletionCondition {
    CommandSuccess { command: String, expected_exit_code: i32 },
    OutputContains { text: String, case_sensitive: bool },
    OutputMatches { pattern: String },
    All { conditions: Vec<CompletionCondition> },

pub enum Evaluator {

    Adversarial { primary: WorkerId, adversary: WorkerId },

pub enum GoalStatus {
    Pending,
    Active,
    Evaluating,
    Converged,
    Iterating { feedback: String },
    Failed { reason: String },

    Cancelled,
}

pub async fn reconcile_goal(&mut self, goal: &mut Goal) -> GoalStatus {
    loop {
        // 1. 预算检查
        if goal.token_budget.map(|b| goal.token_used >= b).unwrap_or(false) {
            return GoalStatus::BudgetExhausted;
        }
        if goal.iterations.len() as u32 >= goal.max_iterations {
            return GoalStatus::Failed { reason: "Max iterations exceeded".into() };
        }

        // 2. 派发给 Worker 执行
        let worker_id = goal.assigned_worker.as_ref().unwrap();
        let result = self.dispatch_to_worker(worker_id, goal).await?;

        // 3. 评估
        goal.status = GoalStatus::Evaluating;
        let eval_result = self.evaluator.eval(&goal.completion_condition, &result).await?;

        if eval_result.passed {
            goal.status = GoalStatus::Converged;
            goal.converged_at = Some(now_ms());
            return GoalStatus::Converged;
        }

        // 4. 追加反馈，进入下一轮迭代
        goal.iterations.push(IterationRecord { /* ... */ });
        goal.status = GoalStatus::Iterating {
            feedback: eval_result.feedback,
        };
    }
}

#### 3.1 Star 拓扑实现

```rust
pub async fn execute_star(&mut self, sub_goals: Vec<Goal>) -> Result<(), SwarmError> {
    let mut handles = Vec::new();
    for mut goal in sub_goals {
        let worker = self.assign_worker(&goal)?;
        goal.assigned_worker = Some(worker);
        let handle = tokio::spawn(async move {
            reconcile_goal(&mut goal).await
        });
        handles.push(handle);
    }
    // 等待所有子 Goal 完成
    let results = futures::future::join_all(handles).await;
    // 检查是否全部 Converged
    if results.iter().all(|r| matches!(r, Ok(GoalStatus::Converged))) {
        Ok(())
    } else {
        Err(SwarmError::PartialFailure)
    }
}
```

#### 3.2 Chain 拓扑实现

用真实 Goal 执行替换 `execute_chain()` 的占位符：
```rust
pub async fn execute_chain(&mut self, ordered_goals: Vec<Goal>) -> Result<(), SwarmError> {
    let mut prev_output = String::new();
    for mut goal in ordered_goals {
        // 将前一阶段输出注入当前 Goal 描述
        if !prev_output.is_empty() {
            goal.description = format!("{}\n\n上下文:\n{}", goal.description, prev_output);
        }
        let status = self.reconcile_goal(&mut goal).await?;
        match status {
            GoalStatus::Converged => {
                prev_output = goal.iterations.last()
                    .map(|i| i.output.clone())
                    .unwrap_or_default();
            }
            _ => return Err(SwarmError::ChainBroken { goal_id: goal.id }),
        }
    }
    Ok(())
}
```

## 八、给 GLM5/Qwen3.7plus 的执行纪律

1. **先修后写**: 不要绕过已有 bug 去写新功能。Phase 0 的 CRITICAL 问题不修完，不写 Phase 1 的一行代码。
2. **每修一个 bug 跑一次编译**: `cargo check` + `npx vue-tsc --noEmit`。不要攒 10 个修复后一起验证。
3. **不要"顺手"加新功能**: 修复计划里没有的文件不要创建，没有的接口不要添加。
4. **假实现改为显式 TODO**: 如果某个方法暂时无法实现，`throw new Error('Not implemented: #issue-xxx')` 或 `todo!("#issue-xxx")`。不要返回假数据。
5. **测试与修复同步提交**: 每个 Phase 的最后一个 commit 包含对应的测试。
6. **不要修改 Phase 顺序**: 如果某个 Phase 卡住了，记录问题并报告，不要跳到下一个 Phase。
7. **commit 格式**: `fix(phase-N): 简要描述修复内容`，body 中包含修复的 issue 编号。
