## 三、仍需解决的问题

### C-1. [CRITICAL] 代码双写——src-tauri/src/ 与 crates/swarm-engine/src/ 两套不兼容实现

**这是项目唯一剩余的 CRITICAL 问题，三轮验证 13 项子声明全部确认。**

主应用（`src-tauri/src/`）和 crate（`crates/swarm-engine/src/`）对 Goal、Topology、Reconcile、QueenLease、GoalGraph 有各自独立的实现，字段名、类型签名、并发模型全部不同。具体差异：

- Goal: `assigned_worker: Option<WorkerId>` vs `executor: String`；`token_budget: Option<u64>` vs `u64`；`dependencies` vs `depends_on`；`iterations` vs `iteration_log`；`u64` 时间戳 vs `DateTime<Utc>`
- Topology: enum 函数式 vs trait struct 式；crate 同步版是假实现
- Reconcile: SwarmAgentAdapter 同步 vs WorkerExecutor async
- 主二进制仅从 crate 导入 `GoalOutcome` 和 `EchoExecutor`，核心类型使用 src-tauri/src/ 版本

**建议**：以 `src-tauri/src/` 为权威版本（它与 TS 前端对齐、被 Tauri 命令直接调用），让 swarm-engine crate 直接 re-export 或依赖 src-tauri/src/ 的公共类型。

### H-1. [HIGH] ACP Server 是 scaffold

`src/lib/acp-protocol/server.ts` 标注 `@deprecated`，`start()` 方法仅打印 warn 日志。`registerDefaultHandlers()` 有逻辑实现，但 `start()` 从未监听端口。

**说明**：前端通过 `connectToBackend()` 连接 Tauri 后端，ACP Server 类是为纯 Web 模式预留的。如果纯 Web 模式不需要，可以移除这个 scaffold。

### H-2. [HIGH] Crate topology 同步版是假实现

`crates/swarm-engine/src/topology.rs` 中 `StarTopology::execute()` 和 `ChainTopology::execute()` 直接返回 `Converged { iterations: 1, tokens_used: 1000 }`。代码已标注 `DEPRECATED`，提示使用 Async 版本。

### M-1. [MEDIUM] 残留 mock 数据

| 文件 | 问题 |
|------|------|
| stores/agent-realtime.ts | 硬编码 3 个 mock agent |
| stores/token-optimizer.ts | initMockHistory / getMockStats |
| lib/collaboration/mock-data-generator.ts | 完整 mock 数据生成器 |
| lib/orchestrator.ts | TODO: trigger actual agent execution |
| lib/self-improvement/adaptive-strategy.ts | 硬编码 0.8 成功率 |

### M-2. [MEDIUM] reconcile_once() 同步阻塞

src-tauri/src/reconcile.rs 使用 `std::thread::sleep` 轮询 Worker 状态，阻塞调用线程。crate 版本是 async 实现但因双写未被主应用使用。统一双写后此问题自然解决。

### M-3. [MEDIUM] Event Protocol → WebSocket 桥接未完成

event-bus crate 有完整的 pub/sub 实现，但未见与前端 WebSocket 的实际连接。前端通过 Tauri 事件系统（`app_handle.emit()`）接收 swarm 事件，这不是标准的 Event Protocol 通道。

### L-1. [LOW] Demo 路由页面

router.ts 中有 6 个路由标记 `meta: { isDemo: true }`：/status、/monitor、/hermes、/task-graph、/collaboration、/token-optimizer。

### L-2. [LOW] .goal 在线编辑器缺失

UI 中没有 .goal 文件的可视化编辑功能，只有 GoalGraphView 中的表单创建。

### L-3. [LOW] goal-api / stores/goal 无单元测试

TypeScript 15 个测试文件（294 测试）中，goal-api.ts 和 stores/goal.ts 没有专门的测试覆盖。
