# RFC-001: Goal-Driven Heterogeneous Swarm Orchestration

> **状态**: Draft
> **创建时间**: 2026-06-09 10:00
> **作者**: ACP-Swarm Design Team
> **参考**: Codex CLI `/goal` (v0.128.0), Claude Code `/goal` (v2.1.139), Kubernetes Reconcile Loop

---

## 摘要

本文档定义 acp-swarm 的核心编排模型：**Goal-Driven Execution**。

传统编排器给 Worker 分配"任务"（Task），任务有固定的执行步骤和一次性的成功/失败判定。Goal-Driven 模型给 Worker 分配"目标"（Goal），目标有明确的**完成条件**（Completion Condition）和独立的**评估器**（Evaluator）。Worker 不是一次性执行，而是进入 **Reconcile Loop**——执行、评估、反馈、再执行——直到完成条件满足（Converged）或预算耗尽。

这一模型使得蜂群编排从"任务分发器"升级为"目标收敛引擎"。Star 拓扑和 Chain 拓扑不再是两种独立的执行模式，而是 Goal 依赖图的两种特例。

---

## 动机

### 现有模型的缺陷

acp-swarm 前身（acp-ui）的 `swarm_orchestrator.rs` 使用 `SwarmTask` + `AgentResult` 模型：

```
提交 SwarmTask → 分配给 Agents → 收集 AgentResult → 合并
```

问题：
1. **Agent 说自己"完成了"不等于"做对了"**。`AgentResult.success: true` 是 Agent 自己判断的，没有客观验证。
2. **一次性执行**。任务失败后只能整体重试，不能带着"哪里错了"的反馈继续迭代。
3. **没有终止条件的形式化定义**。Star 拓扑的"合并结果"到底算成功还是失败？没有程序化判定。
4. **Token 消耗无控制**。Agent 可以在一个任务上消耗无限 Token。

### Goal-Driven 模型如何解决

| 缺陷 | Goal-Driven 解法 |
|------|-----------------|
| 自我判定成功 | Executor/Evaluator 分离——Worker 干活，Queen 验证 |
| 一次性执行 | Reconcile Loop——未收敛则带反馈继续迭代 |
| 无终止条件 | CompletionCondition——客观可执行的验证命令 |
| Token 无控制 | token_budget + max_iterations——双重保护 |

## 一、核心数据结构

### 1.1 Goal（Rust 定义）

**文件**: `crates/swarm-engine/src/goal.rs`

```rust
use serde::{Deserialize, Serialize};
use chrono::{DateTime, Utc};

/// Goal —— 蜂群编排的核心抽象
/// 
/// 一个 Goal 代表一个需要达成的目标。它有明确的完成条件、独立的评估器、
/// Token 预算和最大迭代轮数。Worker 执行 Goal 进入 Reconcile Loop，
/// 直到 Converged（条件满足）或 BudgetExhausted/MaxIterReached。
///
/// # Example
/// ```
/// let goal = Goal {
///     id: "goal-001".into(),
///     description: "All unit tests pass".into(),
///     completion_condition: CompletionCondition::CommandSuccess {
///         command: "npm".into(),
///         args: vec!["test".into()],
///         cwd: Some("/project".into()),
///     },
///     evaluator: Evaluator::Auto,
///     executor: "codex-worker".into(),
///     depends_on: vec![],
///     token_budget: 100_000,
///     max_iterations: 10,
///     ..Goal::default()
/// };
/// ```
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Goal {
    // === 身份 ===
    /// 唯一标识
    pub id: String,
    /// 人类可读的目标描述
    /// 在 Reconcile Loop 中，每轮迭代会追加评估反馈到此描述末尾
    pub description: String,
    /// 所属的蜂群任务 ID（顶层 Goal 的 parent_task_id == 自身 id）
    pub parent_task_id: String,
    /// 父 Goal ID（用于嵌套 Goal；顶层 Goal 为 None）
    pub parent_goal_id: Option<String>,

    // === 完成条件 ===
    /// 什么算"做完了"——客观可验证的条件
    pub completion_condition: CompletionCondition,

    // === 角色分配 ===
    /// 评估器——谁来验证完成条件
    pub evaluator: Evaluator,
    /// 执行者——谁来干活（Worker ID）
    pub executor: String,

    // === 依赖关系 ===
    /// 必须先 Converged 的 Goal ID 列表
    /// 空列表 = 无依赖，可立即执行
    pub depends_on: Vec<String>,

    // === 预算与限制 ===
    /// Token 预算上限（累计，跨迭代轮次）
    pub token_budget: u64,
    /// 已消耗的 Token 数（每轮迭代累加）
    pub tokens_used: u64,
    /// 最大迭代轮数（防止无限循环）
    pub max_iterations: u32,
    /// 当前迭代轮数（从 0 开始）
    pub current_iteration: u32,
    /// 单轮执行超时（毫秒）
    pub per_iteration_timeout_ms: u64,

    // === 状态 ===
    /// 当前状态
    pub status: GoalStatus,
    /// 每轮迭代的评估记录
    pub iteration_log: Vec<IterationRecord>,

    // === 元数据 ===
    pub created_at: DateTime<Utc>,
    pub converged_at: Option<DateTime<Utc>>,
    /// Worker 产出的文件路径列表（用于 Checkpoint）
    pub output_files: Vec<String>,
    /// 自由格式的元数据（Token 细分、Tool 调用次数等）
    pub metadata: serde_json::Value,
}

impl Goal {
    pub fn is_terminal(&self) -> bool {
        matches!(
            self.status,
            GoalStatus::Converged
                | GoalStatus::BudgetExhausted
                | GoalStatus::MaxIterReached
                | GoalStatus::Failed(_)
                | GoalStatus::Cancelled
        )
    }

    pub fn is_converged(&self) -> bool {
        matches!(self.status, GoalStatus::Converged)
    }

    /// 剩余预算
    pub fn remaining_budget(&self) -> u64 {
        self.token_budget.saturating_sub(self.tokens_used)
    }

    /// 剩余迭代轮数
    pub fn remaining_iterations(&self) -> u32 {
        self.max_iterations.saturating_sub(self.current_iteration)
    }

    /// 追加迭代反馈到描述中（让 Worker 下一轮能看到"上一轮为什么没过"）
    pub fn append_feedback(&mut self, iteration: u32, feedback: &str) {
        self.description = format!(
            "{}\n\n---\n[Iteration {} feedback @ {}]:\n{}",
            self.description,
            iteration,
            Utc::now().format("%H:%M:%S"),
            feedback
        );
    }
}

impl Default for Goal {
    fn default() -> Self {
        Self {
            id: String::new(),
            description: String::new(),
            parent_task_id: String::new(),
            parent_goal_id: None,
            completion_condition: CompletionCondition::QueenJudgment {
                criteria: "Task completed satisfactorily".into(),
            },
            evaluator: Evaluator::Queen,
            executor: String::new(),
            depends_on: vec![],
            token_budget: 100_000,
            tokens_used: 0,
            max_iterations: 10,
            current_iteration: 0,
            per_iteration_timeout_ms: 300_000,  // 5 分钟
            status: GoalStatus::Pending,
            iteration_log: vec![],
            created_at: Utc::now(),
            converged_at: None,
            output_files: vec![],
            metadata: serde_json::Value::Null,
        }
    }
}
```

### 1.2 CompletionCondition（完成条件）

```rust
/// 完成条件 —— 客观可验证
///
/// 设计原则：
/// 1. 每个条件都必须能程序化执行（不是"代码质量好"这种主观判断）
/// 2. 条件可以组合（All/Any 形成条件树）
/// 3. 条件的执行结果必须是确定性的（相同输入 → 相同输出）
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum CompletionCondition {
    /// 命令退出码为 0 即视为满足
    /// 
    /// 典型用例：编译检查、测试运行
    /// - `npm test` → 所有测试通过
    /// - `cargo check` → 编译无错误
    /// - `vue-tsc --noEmit` → TypeScript 类型正确
    CommandSuccess {
        command: String,
        args: Vec<String>,
        /// 执行目录（相对于 workspace root）
        cwd: Option<String>,
        /// 环境变量（可选）
        env: Option<std::collections::HashMap<String, String>>,
    },

    /// 命令的标准输出包含指定文本
    ///
    /// 典型用例：lint 检查（输出中包含 "0 errors"）
    OutputContains {
        command: String,
        args: Vec<String>,
        cwd: Option<String>,
        /// 必须包含的文本
        pattern: String,
        /// 是否大小写敏感
        case_sensitive: bool,
    },

    /// 命令的标准输出匹配正则
    ///
    /// 典型用例：覆盖率报告（"Coverage: 85.3%" 且数字 > 80）
    OutputMatches {
        command: String,
        args: Vec<String>,
        cwd: Option<String>,
        /// 正则表达式
        regex: String,
    },

    /// 所有子条件都必须满足（逻辑 AND）
    ///
    /// 典型用例：顶层 Goal = 编译通过 AND 测试通过 AND 文档生成成功
    All {
        conditions: Vec<CompletionCondition>,
    },

    /// 任一子条件满足即可（逻辑 OR）
    ///
    /// 典型用例：至少一个 linter 通过
    Any {
        conditions: Vec<CompletionCondition>,
    },

    /// 文件存在且（可选）内容匹配
    ///
    /// 典型用例：确认生成文件存在、配置文件格式正确
    FileCheck {
        /// 文件路径（相对于 workspace root）
        path: String,
        /// 内容匹配模式（可选；None = 只检查文件存在）
        content_contains: Option<String>,
        /// 内容匹配正则（可选）
        content_matches: Option<String>,
        /// 文件大小上限（字节；防止生成超大文件）
        max_size_bytes: Option<u64>,
    },

    /// HTTP 端点返回 2xx
    ///
    /// 典型用例：API 部署后验证服务可用
    HttpHealthCheck {
        url: String,
        method: String,  // GET, POST, etc.
        expected_status: Option<u16>,  // 默认 200
        body_contains: Option<String>,
    },

    /// Queen 主观判断（最后手段）
    ///
    /// 当无法用命令验证时使用（如"架构设计是否合理"）
    /// Queen 根据 criteria 描述自行判断
    QueenJudgment {
        criteria: String,
    },
}
```

### 1.3 CompletionCondition 评估器实现

```rust
/// 完成条件评估结果
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct EvaluationResult {
    /// 条件是否满足
    pub converged: bool,
    /// 人类可读的评估反馈
    /// converged=true: "All 15 tests passed in 2.3s"
    /// converged=false: "3 tests failed: test_login, test_signup, test_logout"
    pub feedback: String,
    /// 命令的标准输出（用于调试）
    pub stdout: Option<String>,
    /// 命令的标准错误（用于调试）
    pub stderr: Option<String>,
    /// 执行耗时（毫秒）
    pub duration_ms: u64,
    /// 子条件评估结果（仅 All/Any 有值）
    pub sub_results: Option<Vec<EvaluationResult>>,
}

/// 完成条件评估引擎
pub struct ConditionEvaluator;

impl ConditionEvaluator {
    /// 评估一个完成条件
    pub async fn evaluate(
        condition: &CompletionCondition,
        workspace_root: &str,
    ) -> EvaluationResult {
        match condition {
            CompletionCondition::CommandSuccess { command, args, cwd, env } => {
                Self::eval_command(command, args, cwd.as_deref(), env.as_ref(), workspace_root)
                    .await
            }
            CompletionCondition::OutputContains {
                command, args, cwd, pattern, case_sensitive,
            } => {
                Self::eval_output_contains(
                    command, args, cwd.as_deref(), pattern, *case_sensitive, workspace_root,
                ).await
            }
            CompletionCondition::OutputMatches { command, args, cwd, regex } => {
                Self::eval_output_matches(command, args, cwd.as_deref(), regex, workspace_root)
                    .await
            }
            CompletionCondition::All { conditions } => {
                Self::eval_all(conditions, workspace_root).await
            }
            CompletionCondition::Any { conditions } => {
                Self::eval_any(conditions, workspace_root).await
            }
            CompletionCondition::FileCheck {
                path, content_contains, content_matches, max_size_bytes,
            } => {
                Self::eval_file_check(
                    path, content_contains.as_deref(), content_matches.as_deref(),
                    *max_size_bytes, workspace_root,
                ).await
            }
            CompletionCondition::HttpHealthCheck {
                url, method, expected_status, body_contains,
            } => {
                Self::eval_http_health(url, method, *expected_status, body_contains.as_deref())
                    .await
            }
            CompletionCondition::QueenJudgment { criteria } => {
                // QueenJudgment 不在这里评估——由 SwarmOrchestrator 调用 Queen Worker 判断
                EvaluationResult {
                    converged: false,
                    feedback: format!("Requires Queen judgment: {}", criteria),
                    stdout: None,
                    stderr: None,
                    duration_ms: 0,
                    sub_results: None,
                }
            }
        }
    }

    /// 执行命令并检查退出码
    async fn eval_command(
        command: &str,
        args: &[String],
        cwd: Option<&str>,
        env: Option<&std::collections::HashMap<String, String>>,
        workspace_root: &str,
    ) -> EvaluationResult {
        let exec_dir = cwd
            .map(|c| format!("{}/{}", workspace_root, c))
            .unwrap_or(workspace_root.to_string());

        let start = std::time::Instant::now();

        let mut cmd = tokio::process::Command::new(command);
        cmd.args(args)
            .current_dir(&exec_dir)
            .stdout(std::process::Stdio::piped())
            .stderr(std::process::Stdio::piped());

        if let Some(env_vars) = env {
            for (k, v) in env_vars {
                cmd.env(k, v);
            }
        }

        match cmd.output().await {
            Ok(output) => {
                let stdout = String::from_utf8_lossy(&output.stdout).to_string();
                let stderr = String::from_utf8_lossy(&output.stderr).to_string();
                let duration_ms = start.elapsed().as_millis() as u64;

                if output.status.success() {
                    EvaluationResult {
                        converged: true,
                        feedback: format!(
                            "Command `{} {}` succeeded (exit 0) in {}ms",
                            command, args.join(" "), duration_ms
                        ),
                        stdout: Some(stdout),
                        stderr: Some(stderr),
                        duration_ms,
                        sub_results: None,
                    }
                } else {
                    let exit_code = output.status.code().unwrap_or(-1);
                    // 提取失败的测试名/错误信息作为反馈
                    let error_summary = Self::extract_error_summary(&stdout, &stderr);
                    EvaluationResult {
                        converged: false,
                        feedback: format!(
                            "Command `{} {}` failed (exit {}): {}",
                            command, args.join(" "), exit_code, error_summary
                        ),
                        stdout: Some(stdout),
                        stderr: Some(stderr),
                        duration_ms,
                        sub_results: None,
                    }
                }
            }
            Err(e) => EvaluationResult {
                converged: false,
                feedback: format!("Failed to execute `{} {}`: {}", command, args.join(" "), e),
                stdout: None,
                stderr: Some(e.to_string()),
                duration_ms: start.elapsed().as_millis() as u64,
                sub_results: None,
            },
        }
    }

    /// 执行命令并检查输出包含
    async fn eval_output_contains(
        command: &str,
        args: &[String],
        cwd: Option<&str>,
        pattern: &str,
        case_sensitive: bool,
        workspace_root: &str,
    ) -> EvaluationResult {
        let mut result = Self::eval_command(command, args, cwd, None, workspace_root).await;

        let output = format!(
            "{}{}",
            result.stdout.as_deref().unwrap_or(""),
            result.stderr.as_deref().unwrap_or(""),
        );

        let (haystack, needle) = if case_sensitive {
            (output.clone(), pattern.to_string())
        } else {
            (output.to_lowercase(), pattern.to_lowercase())
        };

        result.converged = haystack.contains(&needle);
        result.feedback = if result.converged {
            format!("Output contains '{}'", pattern)
        } else {
            format!(
                "Output does NOT contain '{}'. Actual output (truncated): {}",
                pattern,
                &output[..output.len().min(500)]
            )
        };

        result
    }

    /// 执行命令并检查输出匹配正则
    async fn eval_output_matches(
        command: &str,
        args: &[String],
        cwd: Option<&str>,
        regex: &str,
        workspace_root: &str,
    ) -> EvaluationResult {
        let mut result = Self::eval_command(command, args, cwd, None, workspace_root).await;

        let output = format!(
            "{}{}",
            result.stdout.as_deref().unwrap_or(""),
            result.stderr.as_deref().unwrap_or(""),
        );

        let re = match regex::Regex::new(regex) {
            Ok(r) => r,
            Err(e) => {
                result.converged = false;
                result.feedback = format!("Invalid regex '{}': {}", regex, e);
                return result;
            }
        };

        result.converged = re.is_match(&output);
        result.feedback = if result.converged {
            format!("Output matches regex '{}'", regex)
        } else {
            format!(
                "Output does NOT match regex '{}'. Actual output (truncated): {}",
                regex,
                &output[..output.len().min(500)]
            )
        };

        result
    }

    /// All: 所有子条件都必须满足
    async fn eval_all(
        conditions: &[CompletionCondition],
        workspace_root: &str,
    ) -> EvaluationResult {
        let mut sub_results = Vec::new();
        let mut all_converged = true;
        let mut feedback_parts = Vec::new();
        let mut total_duration = 0u64;

        for (i, cond) in conditions.iter().enumerate() {
            let result = Self::evaluate(cond, workspace_root).await;
            total_duration += result.duration_ms;

            if !result.converged {
                all_converged = false;
            }

            feedback_parts.push(format!(
                "  [{}] {}: {}",
                i + 1,
                if result.converged { "PASS" } else { "FAIL" },
                result.feedback
            ));
            sub_results.push(result);
        }

        EvaluationResult {
            converged: all_converged,
            feedback: format!(
                "All({}): {} passed, {} failed\n{}",
                conditions.len(),
                sub_results.iter().filter(|r| r.converged).count(),
                sub_results.iter().filter(|r| !r.converged).count(),
                feedback_parts.join("\n")
            ),
            stdout: None,
            stderr: None,
            duration_ms: total_duration,
            sub_results: Some(sub_results),
        }
    }

    /// Any: 任一子条件满足即可
    async fn eval_any(
        conditions: &[CompletionCondition],
        workspace_root: &str,
    ) -> EvaluationResult {
        let mut sub_results = Vec::new();
        let mut any_converged = false;
        let mut feedback_parts = Vec::new();
        let mut total_duration = 0u64;

        for (i, cond) in conditions.iter().enumerate() {
            let result = Self::evaluate(cond, workspace_root).await;
            total_duration += result.duration_ms;

            if result.converged {
                any_converged = true;
            }

            feedback_parts.push(format!(
                "  [{}] {}: {}",
                i + 1,
                if result.converged { "PASS" } else { "FAIL" },
                result.feedback
            ));
            sub_results.push(result);
        }

        EvaluationResult {
            converged: any_converged,
            feedback: format!(
                "Any({}): {} passed, {} failed\n{}",
                conditions.len(),
                sub_results.iter().filter(|r| r.converged).count(),
                sub_results.iter().filter(|r| !r.converged).count(),
                feedback_parts.join("\n")
            ),
            stdout: None,
            stderr: None,
            duration_ms: total_duration,
            sub_results: Some(sub_results),
        }
    }

    /// 文件检查
    async fn eval_file_check(
        path: &str,
        content_contains: Option<&str>,
        content_matches: Option<&str>,
        max_size_bytes: Option<u64>,
        workspace_root: &str,
    ) -> EvaluationResult {
        let full_path = format!("{}/{}", workspace_root, path);
        let start = std::time::Instant::now();

        // 检查文件存在
        let metadata = match tokio::fs::metadata(&full_path).await {
            Ok(m) => m,
            Err(_) => {
                return EvaluationResult {
                    converged: false,
                    feedback: format!("File not found: {}", full_path),
                    stdout: None,
                    stderr: None,
                    duration_ms: start.elapsed().as_millis() as u64,
                    sub_results: None,
                };
            }
        };

        // 检查文件大小
        if let Some(max_size) = max_size_bytes {
            if metadata.len() > max_size {
                return EvaluationResult {
                    converged: false,
                    feedback: format!(
                        "File {} is {} bytes, exceeds limit of {} bytes",
                        path, metadata.len(), max_size
                    ),
                    stdout: None,
                    stderr: None,
                    duration_ms: start.elapsed().as_millis() as u64,
                    sub_results: None,
                };
            }
        }

        // 检查内容
        if content_contains.is_some() || content_matches.is_some() {
            let content = match tokio::fs::read_to_string(&full_path).await {
                Ok(c) => c,
                Err(e) => {
                    return EvaluationResult {
                        converged: false,
                        feedback: format!("Cannot read file {}: {}", path, e),
                        stdout: None,
                        stderr: None,
                        duration_ms: start.elapsed().as_millis() as u64,
                        sub_results: None,
                    };
                }
            };

            if let Some(needle) = content_contains {
                if !content.contains(needle) {
                    return EvaluationResult {
                        converged: false,
                        feedback: format!(
                            "File {} does not contain '{}'",
                            path, needle
                        ),
                        stdout: Some(content[..content.len().min(500)].to_string()),
                        stderr: None,
                        duration_ms: start.elapsed().as_millis() as u64,
                        sub_results: None,
                    };
                }
            }

            if let Some(pattern) = content_matches {
                let re = match regex::Regex::new(pattern) {
                    Ok(r) => r,
                    Err(e) => {
                        return EvaluationResult {
                            converged: false,
                            feedback: format!("Invalid regex '{}': {}", pattern, e),
                            stdout: None,
                            stderr: None,
                            duration_ms: start.elapsed().as_millis() as u64,
                            sub_results: None,
                        };
                    }
                };
                if !re.is_match(&content) {
                    return EvaluationResult {
                        converged: false,
                        feedback: format!(
                            "File {} content does not match regex '{}'",
                            path, pattern
                        ),
                        stdout: Some(content[..content.len().min(500)].to_string()),
                        stderr: None,
                        duration_ms: start.elapsed().as_millis() as u64,
                        sub_results: None,
                    };
                }
            }
        }

        EvaluationResult {
            converged: true,
            feedback: format!("File {} exists and passes all checks", path),
            stdout: None,
            stderr: None,
            duration_ms: start.elapsed().as_millis() as u64,
            sub_results: None,
        }
    }

    /// HTTP 健康检查
    async fn eval_http_health(
        url: &str,
        method: &str,
        expected_status: Option<u16>,
        body_contains: Option<&str>,
    ) -> EvaluationResult {
        let start = std::time::Instant::now();
        let expected = expected_status.unwrap_or(200);

        let client = reqwest::Client::builder()
            .timeout(std::time::Duration::from_secs(10))
            .build()
            .unwrap();

        let request = match method.to_uppercase().as_str() {
            "GET" => client.get(url),
            "POST" => client.post(url),
            "HEAD" => client.head(url),
            _ => client.get(url),
        };

        match request.send().await {
            Ok(response) => {
                let status = response.status().as_u16();
                let body = response.text().await.unwrap_or_default();
                let duration_ms = start.elapsed().as_millis() as u64;

                let status_ok = status == expected;
                let body_ok = body_contains
                    .map(|needle| body.contains(needle))
                    .unwrap_or(true);

                let converged = status_ok && body_ok;

                EvaluationResult {
                    converged,
                    feedback: if converged {
                        format!("HTTP {} {} → {} (expected {})", method, url, status, expected)
                    } else {
                        format!(
                            "HTTP {} {} → {} (expected {}). Body check: {}. Body: {}",
                            method, url, status, expected,
                            if body_ok { "pass" } else { "fail" },
                            &body[..body.len().min(200)]
                        )
                    },
                    stdout: Some(body),
                    stderr: None,
                    duration_ms,
                    sub_results: None,
                }
            }
            Err(e) => EvaluationResult {
                converged: false,
                feedback: format!("HTTP {} {} failed: {}", method, url, e),
                stdout: None,
                stderr: Some(e.to_string()),
                duration_ms: start.elapsed().as_millis() as u64,
                sub_results: None,
            },
        }
    }

    /// 从 stdout/stderr 中提取错误摘要（用于反馈给 Worker）
    fn extract_error_summary(stdout: &str, stderr: &str) -> String {
        // 优先从 stderr 提取
        let source = if !stderr.is_empty() { stderr } else { stdout };

        // 取最后 10 行作为错误摘要
        let lines: Vec<&str> = source.lines().collect();
        let start = lines.len().saturating_sub(10);
        lines[start..].join("\n")
    }
}

### 1.4 Evaluator（评估器）

```rust
/// 评估器类型
///
/// 评估器决定"谁来判断 Goal 是否达成"。
/// 核心原则：执行者和评估者必须是不同角色（Executor/Evaluator Separation）。
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Evaluator {
    /// 自动评估：运行 CompletionCondition 中的命令，根据结果判定
    /// 适用于：编译检查、测试运行、文件检查等客观条件
    Auto,

    /// Queen 评估：由 Queen Worker 判断
    /// 适用于：架构设计是否合理、代码质量是否达标等主观条件
    /// Queen 收到 Worker 的产出物 + criteria 描述，自行判断
    Queen,

    /// 对抗性审查：由另一个 Worker 评估
    /// 适用于：代码审查、安全审计等需要"第二双眼睛"的场景
    /// evaluator_worker 不能等于 executor（不能自己审自己）
    Adversarial {
        evaluator_worker: String,
    },

    /// 混合评估：先 Auto 跑客观检查，通过后交给 Queen/Adversarial 做主观评估
    /// 适用于：先跑测试，再人工审查代码质量
    Hybrid {
        auto_condition: CompletionCondition,
        human_evaluator: Box<Evaluator>,  // Queen 或 Adversarial
    },
}

### 1.5 GoalStatus（状态机）

```rust
/// Goal 状态机
///
/// ```text
/// Pending ──→ Active ──→ Evaluating ──→ Converged ✓
///                ↑            │
///                │            │
///                └── Iterating ←┘ (未收敛)
///                
/// 任意状态 ──→ BudgetExhausted ✗
/// 任意状态 ──→ MaxIterReached ✗

    /// Worker 正在执行
    Active,
    /// Queen/Evaluator 正在评估完成条件
    Evaluating,
    /// 目标达成 ✓
    Converged,
    /// 未达成，准备下一轮迭代
    Iterating,
    /// Token 预算耗尽 ✗
    BudgetExhausted,
    /// 达到最大迭代轮数 ✗
    MaxIterReached,
    /// 执行失败（Worker 崩溃、命令不可用等）✗
    Failed(String),
    /// 用户取消 ✗
    Cancelled,
}

## 二、Reconcile Loop 算法

### 2.1 单 Goal 执行循环

```rust
impl SwarmOrchestrator {
    /// 单 Goal 的 Reconcile Loop
    ///
    /// 这是蜂群编排的核心算法。每个 Goal 独立执行此循环。
    ///
    /// 流程：
    /// 1. 检查预算和轮数限制
    /// 2. 发送 Goal 描述给 Worker 执行
    /// 3. 评估完成条件
    /// 4. 如果 Converged → 返回成功
    /// 5. 如果未 Converged → 将评估反馈追加到 Goal 描述，回到步骤 1
    pub async fn reconcile_goal(&self, goal: &mut Goal) -> GoalOutcome {
        loop {
            // === 前置检查 ===

            // 1. Token 预算检查
            if goal.tokens_used >= goal.token_budget {
                goal.status = GoalStatus::BudgetExhausted;
                return GoalOutcome::BudgetExhausted {
                    iterations: goal.current_iteration,
                    tokens_used: goal.tokens_used,
                    last_feedback: goal.iteration_log.last()
                        .map(|r| r.evaluation.feedback.clone())
                        .unwrap_or_default(),
                };
            }

            // 2. 最大迭代检查
            if goal.current_iteration >= goal.max_iterations {
                goal.status = GoalStatus::MaxIterReached;
                return GoalOutcome::MaxIterReached {
                    iterations: goal.current_iteration,
                    tokens_used: goal.tokens_used,
                    last_feedback: goal.iteration_log.last()
                        .map(|r| r.evaluation.feedback.clone())
                        .unwrap_or_default(),
                };
            }

            // === 执行阶段 ===

            // 3. 构建发送给 Worker 的消息
            let worker_message = self.build_worker_message(goal);

            // 4. 调用 Worker 执行
            goal.status = GoalStatus::Active;
            self.emit_goal_status_change(goal).await;

            let execution_result = self.execute_on_worker(
                &goal.executor,
                &worker_message,
                goal.per_iteration_timeout_ms,
            ).await;

            let execution = match execution_result {
                Ok(e) => e,
                Err(e) => {
                    goal.status = GoalStatus::Failed(e.clone());
                    return GoalOutcome::Failed(e);
                }
            };

            goal.tokens_used += execution.tokens_used;

            // === 评估阶段 ===

            // 5. 评估完成条件
            goal.status = GoalStatus::Evaluating;
            self.emit_goal_status_change(goal).await;

            let evaluation = self.evaluate_goal(goal, &execution).await;

            // 6. 记录迭代
            let record = IterationRecord {
                iteration: goal.current_iteration,
                execution_started_at: execution.started_at,
                execution_finished_at: execution.finished_at,
                worker_output: execution.output.clone(),
                tokens_used: execution.tokens_used,
                cumulative_tokens: goal.tokens_used,
                evaluation: evaluation.clone(),
                evaluation_duration_ms: evaluation.duration_ms,
                tool_calls: execution.tool_calls.clone(),
                files_modified: execution.files_modified.clone(),
            };
            goal.iteration_log.push(record);

            // 7. 判断收敛
            if evaluation.converged {
                goal.status = GoalStatus::Converged;
                goal.converged_at = Some(Utc::now());
                self.emit_goal_status_change(goal).await;

                return GoalOutcome::Converged {
                    iterations: goal.current_iteration + 1,
                    tokens_used: goal.tokens_used,
                    final_feedback: evaluation.feedback,
                };
            }

            // === 迭代阶段 ===

            // 8. 未收敛 → 追加反馈，准备下一轮
            goal.current_iteration += 1;
            goal.status = GoalStatus::Iterating;
            goal.append_feedback(goal.current_iteration, &evaluation.feedback);
            self.emit_goal_status_change(goal).await;

            // 继续循环 → 回到步骤 1
        }
    }

    /// 构建发送给 Worker 的消息
    fn build_worker_message(&self, goal: &Goal) -> String {
        let mut msg = format!(
            "## Goal: {}\n\n{}\n\n",
            goal.id, goal.description
        );

        if goal.current_iteration > 0 {
            msg.push_str(&format!(
                "**Iteration {}** (of max {}). {} tokens remaining.\n\n",
                goal.current_iteration + 1,
                goal.max_iterations,
                goal.remaining_budget()
            ));
        }

        msg.push_str("**Completion Condition** (what 'done' looks like):\n");
        msg.push_str(&format!("```json\n{}\n```\n", 
            serde_json::to_string_pretty(&goal.completion_condition).unwrap()
        ));

        msg
    }

    /// 评估 Goal 的完成条件
    async fn evaluate_goal(
        &self,
        goal: &Goal,
        execution: &WorkerExecution,
    ) -> EvaluationResult {
        match &goal.evaluator {
            Evaluator::Auto => {
                // 自动评估：直接运行 CompletionCondition
                ConditionEvaluator::evaluate(
                    &goal.completion_condition,
                    &self.workspace_root,
                ).await
            }

            Evaluator::Queen => {
                // Queen 评估：先跑 Auto，如果通过再让 Queen Worker 审查
                let auto_result = ConditionEvaluator::evaluate(
                    &goal.completion_condition,
                    &self.workspace_root,
                ).await;

                if !auto_result.converged {
                    // 客观条件都不满足，不需要 Queen 审查
                    return auto_result;
                }

                // 客观条件满足，让 Queen 做主观评估
                self.ask_queen_to_judge(goal, execution).await
            }

            Evaluator::Adversarial { evaluator_worker } => {
                // 对抗性审查：让另一个 Worker 评估
                if evaluator_worker == &goal.executor {
                    // 不能自己审自己
                    return EvaluationResult {
                        converged: false,
                        feedback: "Evaluator cannot be the same as executor".into(),
                        stdout: None,
                        stderr: None,
                        duration_ms: 0,
                        sub_results: None,
                    };
                }
                self.ask_adversarial_worker(evaluator_worker, goal, execution).await
            }

            Evaluator::Hybrid { auto_condition, human_evaluator } => {
                // 混合评估：先 Auto 再 Human
                let auto_result = ConditionEvaluator::evaluate(
                    auto_condition,
                    &self.workspace_root,
                ).await;

                if !auto_result.converged {
                    return auto_result;
                }

                // Auto 通过，交给 Human evaluator
                match human_evaluator.as_ref() {
                    Evaluator::Queen => self.ask_queen_to_judge(goal, execution).await,
                    Evaluator::Adversarial { evaluator_worker } => {
                        self.ask_adversarial_worker(evaluator_worker, goal, execution).await
                    }
                    _ => auto_result,  // fallback
                }
            }
        }
    }
}

## 三、Goal 图编排（多 Goal 协调）

### 3.1 Goal Graph 数据结构

```rust
/// Goal 图 —— 管理多个 Goal 之间的依赖关系
///
/// Goal 之间形成 DAG（有向无环图）。
/// 无依赖的 Goal 可以并行执行。
/// 有依赖的 Goal 必须等所有上游 Goal Converged 后才能启动。
pub struct GoalGraph {
    /// 所有 Goal
    goals: HashMap<String, Goal>,
    /// 依赖关系：goal_id → 依赖的 goal_id 列表
    dependencies: HashMap<String, Vec<String>>,
    /// 反向依赖：goal_id → 依赖我的 goal_id 列表（用于触发下游）
    reverse_deps: HashMap<String, Vec<String>>,
}

impl GoalGraph {
    /// 添加 Goal
    pub fn add_goal(&mut self, goal: Goal) {
        let deps = goal.depends_on.clone();
        let id = goal.id.clone();

        self.goals.insert(id.clone(), goal);
        self.dependencies.insert(id.clone(), deps.clone());

        for dep in &deps {
            self.reverse_deps
                .entry(dep.clone())
                .or_default()
                .push(id.clone());
        }
    }

    /// 获取当前可以执行的 Goal（无依赖或所有依赖已 Converged）
    pub fn ready_goals(&self) -> Vec<&Goal> {
        self.goals
            .values()
            .filter(|g| {
                g.status == GoalStatus::Pending
                    && self.all_deps_converged(&g.id)
            })
            .collect()
    }

    /// 检查一个 Goal 的所有依赖是否都已 Converged
    fn all_deps_converged(&self, goal_id: &str) -> bool {
        self.dependencies
            .get(goal_id)
            .map(|deps| {
                deps.iter().all(|dep_id| {
                    self.goals
                        .get(dep_id)
                        .map(|g| g.is_converged())
                        .unwrap_or(false)
                })
            })
            .unwrap_or(true)  // 无依赖 = 可以执行
    }

    /// 检查是否有 Goal 失败导致下游无法继续
    pub fn has_blocked_goals(&self) -> Vec<(String, Vec<String>)> {
        let mut blocked = vec![];

        for (goal_id, deps) in &self.dependencies {
            let failed_deps: Vec<String> = deps
                .iter()
                .filter(|dep_id| {
                    self.goals
                        .get(*dep_id)
                        .map(|g| g.is_terminal() && !g.is_converged())
                        .unwrap_or(false)
                })
                .cloned()
                .collect();

            if !failed_deps.is_empty() {
                blocked.push((goal_id.clone(), failed_deps));
            }
        }

        blocked
    }

    /// 整个图是否全部 Converged
    pub fn all_converged(&self) -> bool {
        self.goals.values().all(|g| g.is_converged())
    }

    /// 是否还有活跃执行的 Goal
    pub fn has_active_goals(&self) -> bool {
        self.goals.values().any(|g| {
            matches!(g.status, GoalStatus::Active | GoalStatus::Evaluating | GoalStatus::Iterating)
        })
    }

    /// 获取图的拓扑排序（用于 UI 展示）
    pub fn topological_order(&self) -> Vec<String> {
        let mut visited = std::collections::HashSet::new();
        let mut order = vec![];

        fn visit(
            id: &str,
            deps: &HashMap<String, Vec<String>>,
            visited: &mut std::collections::HashSet<String>,
            order: &mut Vec<String>,
        ) {
            if visited.contains(id) {
                return;
            }
            visited.insert(id.to_string());
            if let Some(dep_list) = deps.get(id) {
                for dep in dep_list {
                    visit(dep, deps, visited, order);
                }
            }
            order.push(id.to_string());
        }

        for id in self.goals.keys() {
            visit(id, &self.dependencies, &mut visited, &mut order);
        }

        order
    }
}
```

## 四、Queen 选举与 Goal 分解

### 4.1 Queen 的角色

Queen 不只是"评估器"，她还有三个职责：

1. **Goal 分解（Decomposition）**: 收到顶层 Goal 后，Queen 将其拆解为 Sub-Goal 图（定义依赖关系、分配 Worker、设定完成条件）
2. **Goal 评估（Evaluation）**: 评估那些需要主观判断的条件（QueenJudgment 类型）
3. **Goal 协调（Coordination）**: 监控所有 Goal 的状态，触发下游 Goal，处理失败

### 4.2 Goal 分解流程

```rust
impl SwarmOrchestrator {
    /// Queen 分解顶层 Goal
    pub async fn decompose_goal(
        &self,
        top_goal: &Goal,
        available_workers: &[WorkerCapabilityManifest],
    ) -> Result<GoalGraph, String> {
        // 1. 构建 Worker 能力摘要给 Queen
        let worker_summary = available_workers
            .iter()
            .map(|w| format!(
                "- {} ({}): skills={}, max_concurrency={}, max_context={}k tokens",
                w.worker_id, w.worker_type,
                w.skills.iter().map(|s| s.name.clone()).collect::<Vec<_>>().join(", "),
                w.max_concurrency,
                w.max_context_tokens / 1000,
            ))
            .collect::<Vec<_>>()
            .join("\n");

        // 2. 让 Queen 输出 Goal 分解方案（JSON 格式）
        let decompose_prompt = format!(
            r#"You are the Queen orchestrator. Decompose this goal into sub-goals.

## Top-Level Goal
{}

## Available Workers
{}

## Output Format
Respond with a JSON array of sub-goals:
```json
[
  {{
    "id": "sub-goal-1",
    "description": "...",
    "executor": "worker-id",
    "completion_condition": {{ "type": "command_success", "command": "...", "args": ["..."] }},
    "evaluator": {{ "type": "auto" }},
    "depends_on": [],
    "token_budget": 50000,
    "max_iterations": 5
  }}
]
```

Rules:
- Each sub-goal must have an objective, verifiable completion_condition
- Use depends_on to define execution order
- Assign workers based on their skills
- Set reasonable token budgets (50k-100k per sub-goal)
- Set max_iterations to 3-5 for most goals
"#,
            top_goal.description,
            worker_summary
        );

        let queen_response = self
            .execute_on_worker(&top_goal.executor, &decompose_prompt, 30_000)
            .await?;

        // 3. 解析 Queen 的输出为 Goal 列表
        let sub_goals: Vec<Goal> = self.parse_queen_decomposition(&queen_response.output)?;

        // 4. 构建 Goal 图
        let mut graph = GoalGraph::new();
        graph.add_goal(top_goal.clone());
        for sub_goal in sub_goals {
            graph.add_goal(sub_goal);
        }

        // 5. 验证：无循环依赖
        if graph.has_cycles() {
            return Err("Goal graph has circular dependencies".into());
        }

        Ok(graph)
    }
}
```

### 5.2 Pinia Store

**文件**: `src/stores/goals.ts`

```typescript
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import { invokeOrProxy } from '../lib/host';
import type { Goal, GoalStatus, GoalOutcome } from '../lib/swarm/goal-types';

export const useGoalStore = defineStore('goals', () => {
  const goals = ref<Map<string, Goal>>(new Map());
  const activeTaskId = ref<string | null>(null);

  // === 计算属性 ===

  const allGoals = computed(() => Array.from(goals.value.values()));

  const pendingGoals = computed(() =>
    allGoals.value.filter(g => g.status === 'pending')
  );

  const activeGoals = computed(() =>
    allGoals.value.filter(g =>
      ['active', 'evaluating', 'iterating'].includes(g.status)
    )
  );

  const convergedGoals = computed(() =>
    allGoals.value.filter(g => g.status === 'converged')
  );

  const failedGoals = computed(() =>
    allGoals.value.filter(g =>
      ['budget_exhausted', 'max_iter_reached', 'failed'].includes(g.status)
    )
  );

  const progress = computed(() => {
    const total = allGoals.value.length;
    if (total === 0) return 0;
    return Math.round((convergedGoals.value.length / total) * 100);
  });

  const totalTokensUsed = computed(() =>
    allGoals.value.reduce((sum, g) => sum + g.tokens_used, 0)
  );

  const totalIterations = computed(() =>
    allGoals.value.reduce((sum, g) => sum + g.current_iteration, 0)
  );

  // === 操作 ===

  async function submitGoal(description: string, options?: {
    completionCondition?: Goal['completion_condition'];
    tokenBudget?: number;
    maxIterations?: number;
  }) {
    const result = await invokeOrProxy('swarm_submit_goal', {
      description,
      options: options || {},
    }) as { task_id: string; goals: Goal[] };

    activeTaskId.value = result.task_id;
    for (const goal of result.goals) {
      goals.value.set(goal.id, goal);
    }

    return result;
  }

  async function cancelGoal(goalId: string) {
    await invokeOrProxy('swarm_cancel_goal', { goalId });
    const goal = goals.value.get(goalId);
    if (goal) {
      goal.status = 'cancelled';
    }
  }

  async function retryGoal(goalId: string) {
    const result = await invokeOrProxy('swarm_retry_goal', { goalId }) as Goal;
    goals.value.set(result.id, result);
  }

  // === 实时更新（通过 Tauri 事件）===

  function onGoalStatusUpdate(event: { goal_id: string; status: GoalStatus }) {
    const goal = goals.value.get(event.goal_id);
    if (goal) {
      goal.status = event.status;
    }
  }

  function onIterationUpdate(event: { goal_id: string; record: Goal['iteration_log'][0] }) {
    const goal = goals.value.get(event.goal_id);
    if (goal) {
      goal.iteration_log.push(event.record);
      goal.current_iteration = event.record.iteration;
      goal.tokens_used = event.record.cumulative_tokens;
    }
  }

  return {
    // state
    goals,
    activeTaskId,
    // computed
    allGoals,
    pendingGoals,
    activeGoals,
    convergedGoals,
    failedGoals,
    progress,
    totalTokensUsed,
    totalIterations,
    // actions
    submitGoal,
    cancelGoal,
    retryGoal,
    // event handlers
    onGoalStatusUpdate,
    onIterationUpdate,
  };
});
```

## 七、错误场景与恢复策略

| 场景 | 处理 |
|------|------|
| Worker 在 Goal 执行中崩溃 | Goal 状态 → Failed，如果 Goal 有 Replica Worker，切换到 Replica 重新开始 |
| 完成条件命令不存在（如 `npm` 未安装） | EvaluationResult.converged=false，反馈 "Command not found: npm"，Worker 下一轮可能安装 |
| Token 预算耗尽但条件未满足 | Goal 状态 → BudgetExhausted，UI 提示用户"目标未达成，已消耗 X tokens。选择：追加预算 / 降低条件 / 放弃" |
| 所有迭代都失败（同一错误反复出现） | 在第 3 次迭代后，Queen 介入判断是否应该更换 Worker 或修改 Goal 描述 |
| Goal 依赖链中的某个 Goal Failed | 下游所有 Goal 标记为 Blocked，UI 显示依赖链中断位置 |
| Queen 自身崩溃 | QueenLease 过期 → 自动选举新 Queen → 新 Queen 接管 Goal Graph 继续执行 |

## 八、替代方案

### 方案 A：固定步骤流水线（当前 acp-ui 方案）

每个 Stage 固定执行一次，成功则进入下一个 Stage。

**不采用的原因**：无法处理"第一次没做对"的场景。Worker 写了有 bug 的代码，流水线直接标记 Failed，需要人工介入。Goal 模型让 Worker 自动迭代修复。

### 方案 B：纯人工审批

每个 Stage 完成后人工 review，决定是否继续。

**不采用的原因**：效率极低。Goal 模型的 Auto Evaluator 可以自动验证客观条件（编译、测试、文件），只有主观条件（代码质量、架构合理性）才需要人工。

### 方案 C：无限重试

失败就一直重试，直到成功。

**不采用的原因**：Token 消耗不可控。Goal 模型的 `token_budget` + `max_iterations` 提供了硬性上限。

## 九、未解决问题

1. **Goal 分解的质量保证**: Queen 分解出的 Sub-Goal 如果完成条件写错了怎么办？可能需要一个"Goal 分解验证器"——检查每个 Sub-Goal 的 CompletionCondition 是否可执行。

2. **跨 Worker 的状态同步**: Sub-Goal A 修改了文件，Sub-Goal B 依赖这个文件。如果 A 和 B 并行执行（而非串行），B 看到的是 A 修改前还是修改后的文件？可能需要 Git workspace 分支隔离。

3. **Goal 的动态调整**: 执行过程中能否修改 Goal 的完成条件？比如 A Converged 后发现原来给 B 设定的条件太松，能否加强？

4. **多租户 Goal 调度**: 多个用户同时提交 Goal，Worker 如何公平调度？可能需要 Goal 优先级队列。

5. **Goal 的持久化与恢复**: 如果 acp-swarm 进程重启，正在执行的 Goal 能否从 Checkpoint 恢复？
