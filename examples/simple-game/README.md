# 简单游戏示例

这个示例展示了如何使用 ACP-UI 开发一个简单的 Godot 游戏。

## 📁 项目结构

```
simple-game/
├── project.godot          # Godot 项目文件
├── scenes/
│   └── Main.tscn         # 主场景
└── scripts/
    ├── Player.gd         # 玩家脚本
    └── Enemy.gd          # 敌人脚本
```

## 🎮 游戏说明

这是一个简单的 2D 游戏：
- 使用方向键控制玩家移动
- 躲避随机出现的敌人
- 收集金币获得分数

## 🚀 在 ACP-UI 中使用

1. 打开 ACP-UI
2. 点击 "New Operator"
3. 选择这个示例项目目录
4. 启动操作员
5. 处理审批请求
6. 查看 Agent 的修改建议

## 📝 学习目标

通过这个示例，你将学习：
- 如何在 ACP-UI 中创建操作员
- 如何处理审批请求
- 如何查看 Agent 的修改
- 如何使用文件工具
